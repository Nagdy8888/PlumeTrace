## Method

Test leaks are generated with the truth model, which differs on purpose from the inversion physics: Pasquill-Gifford/Martin dispersion coefficients (the inversion uses Briggs rural), wind meander, gusty wind speed, building-wake dilution and sensor noise. Some sources are off-list: 2 to 10 m from a candidate, so no candidate is exactly right. The background of each sensor is estimated as the 5th percentile of its 10-minute means. A leak case is correct when the true candidate (on-list) or a candidate within 10 m of the true source (off-list) is ranked first (top-1) or in the first three (top-3), with the no-source hypothesis removed; an inconclusive result counts as wrong. Rate error uses only conclusive, top-1-correct cases. Cases, seeds, thresholds and coefficients are fixed before the run and are not tuned to the results; the numbers above are exactly what the run produced. The station and all data are simulated (evidence label: synthetic).
