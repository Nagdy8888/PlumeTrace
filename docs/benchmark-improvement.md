## Method

The Task 8 inversion assumes a narrow plume along the 10-minute mean wind direction. The meander-aware inversion also receives, for every window, the circular standard deviation of the 10 s met-mast wind direction, and widens the horizontal spread of the plume: sigma_y,eff squared is sigma_y squared plus (x times the spread in radians) squared, with sigma_z unchanged (a project derivation, see docs/reference/ENGINEERING.md). The spread is measured from the data; the truth model's setting is never used. Both methods run on the same cases and the same generated data (each case seeds its own generator), so the comparison is paired. The fresh seed had never been run before this report; the metric definitions, the adoption rule and all other values were fixed in advance (pre-registered 2026-11-14) and are not tuned to the results. The published column is the run of seed 20261112 at revision 23b8703, which stays the unchanged 'before'. The benchmark uses no sensor faults or drift. Evidence label: synthetic (simulated station, simulated sensors). One seed: the sampling error on a proportion near 0.4 is about plus or minus 0.07.
