# PlumeTrace UX profile

Read by UI skills (anti-slop, impeccable, visual-taste) before changing layout, colour or type.
Full rules: `.claude/skills/frontend-design/references/anti-slop.md` and
`.claude/skills/frontend-design/references/control-room-workspace.md`.

## Product
Industrial control-room software for methane leak detection at a gas compressor station.
Users: process, operations and emissions engineers. It must read like professional HMI/SCADA-grade
software built by an engineering team — never like an AI-generated SaaS landing page.

## Visual direction
- Dark, neutral grey surfaces in 3–4 levels; colour is reserved for meaning (alarm priorities,
  methane concentration, AI candidate highlight, approval state).
- One accent hue for primary actions. No gradients on controls.
- Dense but ordered: tables, trends, tags, units. Numbers in tabular figures with units.
- Typography: one considered sans family plus one monospace for tags/values, chosen for this
  product (not the default stack), with a strict type scale.
- Motion only to explain cause and effect (new alarm, camera moves to candidate, state change).

## Banned (extends the anti-slop skill)
- Purple/indigo/violet "AI" gradients, gradient text, glowing neon outlines, aurora/blob backgrounds.
- Glassmorphism (`backdrop-filter`) on product panels.
- Sparkle/magic-wand/robot icons or emoji to signal "AI"; emoji anywhere in the UI.
- Marketing copy: "Unlock", "Supercharge", "Seamless", "Revolutionize", "Elevate", "Harness the
  power", "cutting-edge", "next-generation", "AI-powered" as decoration, "Welcome back!" banners.
- Identical rounded cards for everything, same soft shadow everywhere, `rounded-2xl`+ on panels.
- Decorative pills on static metadata; decorative icons inside inputs; cartoon empty states.
- Stock dashboard filler: fake avatars, fake "users online", sparkline-on-every-tile, donut charts
  without purpose, "+12% this week" badges not backed by data.
- Lorem ipsum, placeholder names, "John Doe", made-up numbers not produced by the backend/replay.
- Fade-and-slide-up entrance on every section; hover-scale on every card; infinite pulsing.
